YMonstr / Privacy

Privacy Policy

Effective date: October 29, 2026 · Contact: maratgood@gmail.com

YMonstr is an owner-operated local toolkit for managing the GameChAInger YouTube channel. The operator is the GameChAInger channel owner, who maintains the Ellmind/Game-ChAInger-YT-Channel repository. This policy covers the toolkit and this public information website.

1. Google and YouTube services

YMonstr uses YouTube API Services, specifically the YouTube Data API v3. Google authorization is completed on Google’s own pages. YMonstr does not request or store your Google password. Google’s processing is described in the Google Privacy Policy.

2. Information accessed and stored

  • Channel and video data: channel IDs and names, video IDs, titles, descriptions, tags, thumbnails or thumbnail references, publication times, visibility, durations, and statistics such as views, likes and comment counts.
  • Playlist data: playlist IDs, titles, descriptions and video membership used to organize the channel.
  • Comments: comment text and identifiers, author channel identifiers and publication status needed to check for duplicates, publish approved comments and verify the result. Reading comment threads can also return public comments written by other users.
  • Authorization credentials: OAuth access tokens, refresh tokens, expiration information and the authorized channel ID, stored locally for API access.
  • Operator-provided content: original video files, thumbnail files, proposed metadata, comment drafts, publication plans and schedules supplied for the operator’s tasks.
  • Local records: API responses, SQLite records, JSON exports, reports, operation logs, upload progress and publication results. These may contain private or scheduled video metadata if the operator has authorized access.
  • Support requests: your email address and the information you choose to include when contacting the operator. Do not send passwords or tokens.

The current toolkit does not request access to Gmail, Drive, Contacts, YouTube Analytics API, or YouTube Reporting API. It uploads original files supplied by the operator; it does not download YouTube audiovisual content.

3. Why the information is used

Information is used to identify the authorized channel, prepare local catalog reports, plan content, upload videos, change approved metadata and thumbnails, apply approved visibility and scheduling settings, maintain playlist membership, publish approved comments, prevent duplicate operations and verify results. Tokens are used only to authenticate authorized requests and refresh access when needed.

The current OAuth permission is https://www.googleapis.com/auth/youtube.force-ssl. It grants broad YouTube read and write capabilities. YMonstr’s current features and the owner’s instructions determine which operations are performed; the permission itself is not limited to a single video or task.

4. Storage and access

The toolkit stores its working data on the operator’s computer in local files and databases. OAuth credentials are stored separately from website files and are excluded from source-control publication. This is local file storage; this policy does not represent it as application-level encrypted storage.

The public website and repository contain information pages and branding assets, not a live channel database or an OAuth sign-in service. The operator is responsible for protecting the computer, restricting file access and keeping credentials and private records out of public repositories, shared folders and backups accessible to others.

5. Sharing and external processing

API requests send the data needed for the requested operation to Google and YouTube. Publishing a video, metadata, playlist item or comment makes that information available through YouTube according to the selected visibility and YouTube’s own behavior. An approved publication action is a disclosure to that audience.

The operator may use separately authorized assistants or service providers, including OpenAI tools or Google Gemini, to help review selected metadata, reports or content drafts. Such processing must be limited to the approved channel-management task and the information needed for it. Private channel data must not be sent to another provider without the authorizing user’s explicit approval. OAuth tokens and client credentials must not be included in assistant prompts or public documents. The receiving provider processes submitted information under its applicable terms and privacy policy: OpenAI Privacy Policy and Google Privacy Policy.

YMonstr does not sell Google user data, use it for targeted advertising, or use it to train generalized artificial intelligence or machine-learning models. Google user data may be disclosed where required by applicable law or to address abuse or security incidents, limited to what is necessary.

6. Retention and deletion

The operator retains only the local data needed for the authorized workflow. Cached YouTube API metadata and other API data subject to YouTube’s 30-day limit must be refreshed or deleted within 30 calendar days. Where YouTube permits longer retention of authorized statistics, the operator must reconfirm authorization and the availability of the underlying resource at least every 30 days. These are operator-managed retention obligations; the current toolkit does not provide an automatic background deletion service.

Tokens are retained only while needed for authorized access. To request deletion of stored user data and credentials, email maratgood@gmail.com with the subject “YMonstr data deletion” and identify the channel concerned. The operator may request reasonable confirmation that you control the channel. Requested app data deletion is handled as soon as possible and within seven calendar days, including related local exports and backups under the operator’s control.

You can revoke YMonstr’s access at any time through Google Account connections, also available through Google’s permissions settings. Revocation stops future authorized access; it does not itself erase existing local files. The operator must remove related stored API data as soon as possible and within 30 calendar days after revocation through Google’s settings. If you also request deletion directly from the operator, the seven-day deletion deadline applies.

Deleting YMonstr’s local data does not delete videos, comments, playlists or other content stored by YouTube. Manage those resources in YouTube or through a separately authorized operation. Original media files provided by the operator remain under the operator’s control and can be deleted independently.

7. Website hosting, cookies and device data

This static website is hosted on GitHub Pages. It contains no advertising, analytics scripts, tracking pixels, embedded videos, forms, or app cookies, and does not use browser local storage. Requests to GitHub Pages necessarily disclose connection information such as your IP address to the hosting provider, which may keep security and service logs under the GitHub General Privacy Statement. Emailing support uses your email provider and the operator’s email service.

8. Limited Use

YMonstr’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. Changes and contact

Updates will be published on this page with a revised effective date. Before Google user data is used for a materially different purpose, the operator must disclose the change and obtain any additional consent required. For access, correction, deletion, privacy questions or complaints, contact maratgood@gmail.com.
