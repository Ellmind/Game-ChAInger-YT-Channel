# YMonstr

Public information pages for YMonstr, the local YouTube channel management toolkit operated by the GameChAInger channel owner.

- [Application home page](https://ellmind.github.io/Game-ChAInger-YT-Channel/)
- [Privacy Policy](https://ellmind.github.io/Game-ChAInger-YT-Channel/privacy.html)
- [Terms of Service](https://ellmind.github.io/Game-ChAInger-YT-Channel/terms.html)
- Support: [maratgood@gmail.com](mailto:maratgood@gmail.com)

The current desktop workflow reads channel information, uploads original videos, updates approved metadata, thumbnails, visibility and schedules, manages playlists, and publishes reviewed comments using YouTube Data API v3.

This repository contains only the static information site and branding assets. It does not contain the desktop toolkit, OAuth credentials, channel database, private video metadata or an online sign-in service.

## Hosting

GitHub Pages serves the root of the `main` branch. No build tools, JavaScript, third-party fonts, analytics or app cookies are required.

The app's local data-retention and deletion responsibilities are described in the Privacy Policy and are managed by the operator. Publishing these pages does not itself complete Google's OAuth branding, domain or data-access verification.

YMonstr is independent and is not affiliated with or endorsed by Google or YouTube.
